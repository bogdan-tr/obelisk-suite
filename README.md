# Obelisk Suite — downloads

Installers for the [Obelisk](https://github.com/bogdan-tr) suite. The source
lives in private repositories; this one exists to hold the binaries so they
have a stable, public address.

## Installing

Download **Obelisk launcher** from the latest release and install it. Every
other app is installed from inside it — the launcher hands each package to
your own OS installer, so uninstalling works through your system's normal
app list whether or not the launcher is still around.

## Verifying a download

Updates are signed. The app checks every update against a public key
compiled into it and refuses anything that does not verify, so a tampered
release cannot install itself over a working one.
